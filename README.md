# Game Store Madadi

## راه‌اندازی
1. `cp .env.example .env` و مقدارها را پر کنید (ADMIN_PASS حداقل ۱۰ کاراکتر)
2. `npm install && npm start` → http://localhost:3000 — پنل ادمین: `/admin`
3. تست: `npm test` — سلامت سرور: `/healthz`
4. داکر: `docker build -t gsm . && docker run -p 3000:3000 -v gsm-data:/data --env-file .env gsm`

## ساختار
- `server.js` راه‌اندازی، `src/config.js` تنظیمات و اعتبارسنجی env
- `src/db.js` اتصال، مهاجرت‌های نسخه‌دار، تراکنش‌ها، audit
- `src/security.js` هدرهای امنیتی، rate-limit، قفل ورود، هش رمز (scrypt)
- `src/sessions.js` نشست سمت سرور · `src/admin.service.js` منطق ادمین · `src/admin.routes.js` مسیرها
- `src/shop.routes.js` پرداخت ریالی (زرین‌پال) و دلاری (NOWPayments)

## پنل ادمین (`/admin`) — کنترل کامل سایت
- **محصولات:** افزودن/ویرایش/حذف/مخفی‌سازی بازی، آپلود تصویر (JPG/PNG/WEBP تا ۳MB)، پلتفرم، ژانر، رنگ کاور — مستقیم روی ویترین اعمال می‌شود (`/api/games`)
- **سفارش‌ها:** جستجو، فیلتر، تغییر وضعیت، حذف (موجودی برمی‌گردد)، خروجی CSV
- **مشتریان:** فهرست خریداران و مجموع خرید
- **تنظیمات:** نرخ دلار (بدون ری‌استارت)، اطلاعیهٔ بالای سایت، حالت تعمیر (بستن خرید)
- **امنیت:** تغییر رمز از پنل، نشست‌های فعال و خروج از بقیهٔ دستگاه‌ها، گزارش کامل رویدادها
- **پشتیبان:** دانلود دیتابیس با یک کلیک
- نکته: تصاویر آپلودی در `public/images` ذخیره می‌شوند؛ در داکر این پوشه را هم volume کنید تا با ساخت مجدد ایمیج پاک نشود.

## اجرا بدون سرور و هاست (حالت محلی)
فایل `public/admin.html` را با دوبار کلیک در Chrome/Edge باز کنید. پنل خودش تشخیص می‌دهد سرور نیست و با داده‌های ذخیره‌شده در همان مرورگر کار می‌کند (سفارش‌های نمونه دارد). این حالت **سایت واقعی را تغییر نمی‌دهد.**
برای کنترل سایت واقعی روی کامپیوتر خودتان: Node.js را نصب کنید و `start-server.bat` را اجرا کنید.
